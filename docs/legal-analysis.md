# 法律风险分析

> 本文档分析将大衍决开发为独立 App 可能面临的法律风险，以及降低风险的措施。

---

## 一、总体评估

| 场景 | 风险等级 |
|------|----------|
| 个人使用（CLI / 本地脚本） | 🟢 低 |
| 开源桌面 App（免费，本地运行） | 🟡 中低 |
| 商业化 SaaS（托管服务） | 🔴 极高 |
| 仅处理本地文件（砍掉在线下载） | 🟢 低 |

**核心结论**：作为免费开源本地工具，实际被追责的概率很低。同类的 yt-dlp（100K+ stars）、you-get（55K+ stars）、BBDown（20K+ stars）均活跃维护且未被起诉。

---

## 二、逐项分析

### 🔴 高风险：视频下载与平台 ToS 冲突

大衍决的核心功能依赖 `yt-dlp` + `AI Douyin` 从各平台下载视频。这直接违反平台用户协议：

| 平台 | ToS 相关规定 | 风险 |
|------|-------------|------|
| **YouTube** | 明确禁止下载视频（除官方下载按钮外） | 🔴 高 |
| **B 站** | 用户协议禁止未经许可的视频下载、爬取 | 🔴 高 |
| **抖音** | 用户协议禁止抓取、下载视频内容 | 🔴 高 |
| **小红书** | 用户协议禁止数据爬取和内容下载 | 🔴 高 |

**法律依据**：
- 美国：DMCA 反规避条款（17 U.S.C. § 1201）
- 中国：《网络安全法》《数据安全法》，可构成不正当竞争
- 欧盟：DSM Directive Article 17

**典型案例**：
- 2020 年 RIAA 要求 GitHub 下架 youtube-dl，经 EFF 介入后恢复
- 国内视频解析网站被诉不正当竞争，法院支持平台方
- **但均为公司/商业实体被告，个人开源开发者极少被追责**

**为什么个人开发者安全**：
1. 工具中立原则 — 工具本身不侵权，用户如何使用是用户的事
2. 个人开发者没钱可赔 — 追诉 ROI 极低
3. 舆论反噬 — 起诉开源开发者会引起社区强烈反弹
4. 你的项目前面有几十个更大更有名的同类工具

### 🟠 中高风险：第三方视频解析服务

AI Douyin（`ai-douyin.top9.cc`）是第三方视频解析代理：

- 它绕过平台限制，解析视频直链
- 你在 App 中集成它 = 依赖一个法律灰色地带的第三方
- 如果该服务被关闭，App 核心功能瘫痪

**建议**：不内置 API Key，让用户自己申请。你的 App 只是提供一个"填入 Key 即可用"的便利。

### 🟠 中高风险：衍生作品版权

笔记是原视频/文章的衍生作品：

| 场景 | 风险 |
|------|------|
| 用户个人使用笔记 | 🟢 低（个人学习 = 合理使用） |
| 用户公开发布笔记 | 🟠 中（可能侵犯原作者改编权） |
| App 内置"一键分享" | 🔴 高（帮助用户规模化侵权） |

**建议**：笔记默认私有，不提供分享功能。

### 🟡 中等风险：网页爬取

文章模式会爬取知乎/CSDN/微信公众号等内容：

- 中国《反不正当竞争法》第十二条（"互联网专条"）
- 大规模爬取可被认定为妨碍网络服务正常运行
- **但逐个 URL 手动提交 ≠ 大规模爬取**

### 🟢 低风险：开源许可证

- 上游项目：[MIT](https://github.com/imlewc/myriad-mind-skill) ✅
- faster-whisper：[MIT](https://github.com/SYSTRAN/faster-whisper) ✅
- yt-dlp：[Unlicense](https://github.com/yt-dlp/yt-dlp) ✅
- FFmpeg：[LGPL/GPL](https://ffmpeg.org/legal.html) — 作为外部进程调用不触发传染性 ✅

### 🟢 低风险：AI 生成内容

- Anthropic ToS：API 输出版权归用户所有
- 但笔记基于有版权的原视频/文章 → "有瑕疵的所有权"
- 责任在生成和分发内容的用户，而非工具开发者

## 三、风险缓解措施

### ✅ 必须做的

1. **README 顶部免责声明**
2. **不内置任何 API Key 或 Cookie**（让用户自己申请）
3. **不提供分享/发布功能**（笔记默认私有）
4. **保留 MIT 许可证和上游版权声明**
5. **不收费、不加广告**

### ✅ 建议做的

6. **仅处理本地文件模式最安全** — 可设为默认推荐
7. **视频下载前弹出提醒** — "请注意遵守平台用户协议"
8. **不使用 AI Douyin 的默认 API Key** — 引导用户注册自己的
9. **不用"免费下载XX视频"等措辞宣传**

### ❌ 不要做的

1. ❌ 商业化（收费/广告/增值服务）
2. ❌ 做 SaaS（你托管服务帮用户下载 = 直接参与侵权）
3. ❌ 内臵默认 API Key（让用户的请求走你的 Key）
4. ❌ "批量下载""批量搬运"功能
5. ❌ 用"破解""绕过"等措辞

## 四、最坏情况与应对

| 最坏情况 | 概率 | 影响 | 应对 |
|----------|------|------|------|
| GitHub DMCA 下架 | 中低 | 仓库暂时不可用 | 提交 DMCA counter-notice；GitHub 有 100 万美元开发者辩护基金 |
| 被平台发律师函 | 低 | 需要下架相关功能 | 去掉视频下载，只保留本地文件处理 |
| 被起诉 | 极低 | 需要应诉 | 个人开发者 + 免费 + 无商业目的 = 胜诉概率高 |
| AI Douyin 被关闭 | 中 | 抖音/B站/小红书功能失效 | 回退方案：yt-dlp（B站）+ 用户自备 Cookie |
