# 项目结构

> 大衍决 App 的 Monorepo 目录结构、各包职责和模块依赖关系。
> 最后更新：2026-06-14

---

## 顶层目录

```
myriad-mind-app/
├── packages/          # 共享包（跨平台复用）
│   ├── core/          #   纯逻辑 — 类型、Schema、Prompt、计算
│   └── ui/            #   共享 React UI 组件
├── apps/              # 平台应用
│   ├── desktop/       #   Tauri 2.x 桌面端（Rust + React）
│   └── mobile/        #   React Native Expo 移动端（v2 延后）
├── scripts/           # Python 脚本（6 个，作为子进程调度）
├── docs/              # 项目文档
│   └── 项目管理/      #   进度跟踪、任务清单
├── CLAUDE.md          # Claude Code 项目指令
├── README.md          # 项目介绍
└── package.json       # pnpm workspace 根配置
```

## packages/core/ — 共享纯逻辑

跨平台 100% 复用的 TypeScript 纯函数，无 React / Node / 平台 API 依赖。

```
packages/core/src/
├── index.ts           # 统一导出入口
├── types.ts           # 全部类型定义
│                       #   MyriadMindConfig — 配置
│                       #   Note / NoteMetadata — 笔记
│                       #   DashboardData / CultivationInfo — 修为面板
│                       #   InputMode / PipelineStep — 管线
│                       #   TokenEstimate — 灵力预估
├── schema.ts          # Zod 校验 Schema + 默认配置 + 验证函数
├── classifier.ts      # 输入模式识别（8 种：bilibili/youtube/douyin/...）
├── estimator.ts       # 灵力预估算法（Token × 时间 × 费用）
├── note-parser.ts     # 笔记解析（front matter / 标签 / 元数据提取）
├── panel-calc.ts      # 修为面板计算（7 境界映射 + 6 成就判定）
└── prompts/           # MindEngine Prompt 模板
    ├── index.ts       #   统一导出
    ├── note-gen.ts    #   笔记生成（核心 prompt，含"禁止提问"规则）
    ├── summarize.ts   #   AI 摘要
    ├── translate.ts   #   中英翻译
    ├── compare.ts     #   笔记对比
    ├── code-analysis.ts # 代码项目分析
    └── resource-recommend.ts → 合并到 note-gen.ts
```

**被谁依赖：** `packages/ui/`、`apps/desktop/src/`；`apps/mobile/` v2 再接入

## packages/ui/ — 共享 React 组件

桌面端优先使用的 React 组件库，保留 v2 移动端复用空间，CC Switch 暗色风格。

```
packages/ui/src/
├── index.ts           # 统一导出
├── ConfigWizard.tsx   # 多步骤配置向导（7 步）
│                       #   ASR → API 密钥 → 视频 → 功能开关 → 关键帧 → 输出 → 收尾
│                       #   接受 KeychainApi 接口注入，实现 OS 密钥链读写
├── Dashboard.tsx      # 修为面板可视化（境界进度 + 成就徽章 + 统计）
├── NoteRenderer.tsx   # Markdown 笔记渲染（react-markdown + Mermaid + 代码高亮）
└── common/            # 基础 UI 组件
    ├── index.ts       #   统一导出
    ├── Button.tsx     #   按钮（primary/secondary/ghost/danger）
    ├── Card.tsx       #   卡片容器（bordered/elevated/flat）
    └── Input.tsx      #   输入控件（Input / Select / Toggle / Textarea）
```

**被谁依赖：** `apps/desktop/src/`

## apps/desktop/ — Tauri 桌面端

Tauri 2.x 桌面应用，Rust 后端 + React 前端。

### 前端 (`src/`)

```
apps/desktop/src/
├── main.tsx           # React 入口（ReactDOM.createRoot）
├── App.tsx            # 主应用 — 页签布局（炼化 / 修为 / 配置）
├── App.css            # 全局样式（CC Switch 暗色风格）
├── api.ts             # Tauri IPC 封装层
│                       #   - 自动检测 Tauri 环境，非 Tauri 降级为 mock
│                       #   - 密钥链操作（check/read/store）
│                       #   - 管线进度监听（pipeline-progress event）
│                       #   - Python 脚本命令（6 个）
│                       #   - mind-stream 流式监听
├── vite-env.d.ts      # Vite 类型声明
├── hooks/             # 业务 Hook
│   ├── useConfig.ts   #   配置加载 / 首启检测
│   ├── usePipeline.ts #   管线进度事件 + mind-stream 流式监听
│   └── useTheme.ts    #   主题切换（light / dark / system）
├── lib/               # 平台/工具
│   ├── platform.ts    #   平台检测
│   └── utils.ts       #   通用工具
└── components/
    ├── layout/        #   布局：Sidebar / NavButton
    ├── input/         #   炼化输入：InputView（输入控制 + AI 输出区）
    ├── dashboard/     #   修为面板：DashboardView（当前为硬编码示例数据）
    ├── settings/      #   设置：SettingsView + DepsPanel（依赖检测）
    └── log/           #   日志：LogPanel（管线/AI 日志）
```

### Rust 后端 (`src-tauri/src/`)

```
apps/desktop/src-tauri/src/
├── main.rs            # Windows 入口（防止 release 弹控制台窗口）
├── lib.rs             # Tauri Builder — 注册全部 IPC 命令
├── error.rs           # 统一错误类型 AppError（thiserror）
│                       #   PythonScript / MissingDependency / Config / Io / Http / AiApi / Stream / Cancelled
│
└── commands/          # Tauri IPC 命令模块
    ├── mod.rs         #   模块声明（pub mod 声明 10 个模块 + ai/）
    ├── config.rs      #   配置读写 + OS 密钥链
    │                     #   - ~/.myriad-mind-app/config.json（原子写入）
    │                     #   - Windows Credential Manager（CredReadW/CredWriteW）
    │                     #   - 首启检测、配置重置
    ├── deps.rs        #   系统依赖检测
    │                     #   - detect_python: 接受配置路径，校验 >= 3.9
    │                     #   - detect_ffmpeg / detect_ytdlp / detect_gpu
    │                     #   - detect_all_deps: 批量检测
    │                     #   - resolve_python_path: 配置 > venv > PATH 三级回退
    ├── python.rs      #   Python 脚本调度（6 个脚本的类型化封装）
    │                     #   - scripts_dir(): 智能 scripts/ 路径解析（dev/venv/exe）
    │                     #   - run_python_script(): 通用子进程执行
    │                     #   - 6 个 #[tauri::command] 封装:
    │                     #     transcribe_audio / extract_keyframes
    │                     #     download_video / download_youtube_subtitles
    │                     #     install_faster_whisper / list_ai_douyin_tasks
    │                     #   - check_python_env / resolve_python_path / get_whisper_venv_python
    ├── fetch.rs       #   文章 URL 抓取（Rust dom_query + reqwest，本地解析）
    │                     #   非 WebFetch，支持知乎/CSDN/掘金/微信公众号/Wiki 等
    ├── code_project.rs #  代码项目扫描
    │                     #   - 目录树 / 语言识别 / 入口文件分析
    │                     #   - 输出结构化项目画像供 AI 炼化
    ├── notes.rs       #   笔记处理
    │                     #   - 读取 / 列举已生成笔记
    │                     #   - Q&A 追问（基于已有笔记上下文继续提问）
    ├── library.rs     #   .myriad-mind/ 知识库索引 + 指纹去重
    │                     #   - library.json / notes.jsonl / categories.json / fingerprints.json / memory.md
    │                     #   - source_fingerprint 命中时更新而非新建
    │                     #   - 索引层已就绪，前端修为面板消费链路待接入
    ├── pipeline.rs    #   管线编排器（约 2155 行）
    │                     #   - execute_pipeline: 主入口，按 InputMode 分流
    │                     #   - run_text_pipeline: 文章/本地文本 → AI（fetch.rs 抓取）
    │                     #   - run_video_pipeline: 视频 → 下载 → 音频 → ASR → 关键帧 → Vision → AI
    │                     #   - run_audio_pipeline: 音频 → ASR → AI
    │                     #   - run_code_project_pipeline: 代码项目（code_project.rs）→ AI
    │                     #   - 每步 emit pipeline-progress 事件
    ├── fs.rs          #   文件系统操作
    │                     #   - scan_directory: 递归扫描（最多 2 层）
    │                     #   - read_text_file / write_note / cleanup_temp / copy_asset
    └── ai/            #   MindEngine + DeepSeek 客户端（流式）+ 提示词模板渲染
        ├── mod.rs     #     模块声明 + re-export（generate_note/qa_note/run_mind_task/test_deepseek_connection）
        ├── types.rs   #     AI 请求/响应/消息/任务类型（AiTask/MindRequest/MindStreamEvent）
        ├── engine.rs  #     MindEngine — generate_note/qa_note/run_mind_task（prompt 由 PromptManager 渲染）+ Pro/Flash 路由
        ├── deepseek.rs #    DeepSeek V4 Pro / Flash 流式客户端（reasoning_content 分流 + mind-stream emit）
        ├── vision.rs  #     DeepSeek Vision 关键帧截图审查（场景评分 / 嵌入位置选择）
        └── prompt_manager.rs #  PromptManager — 加载 prompts/*.md + minijinja 渲染（变量/条件/include）
```

## scripts/ — Python 脚本

来自上游 [MyClaude/myriad-mind/scripts](https://github.com/yuexingqin97/MyClaude/tree/main/myriad-mind/scripts)，作为黑盒子子进程被 Rust 调度。所有脚本遵循统一约定：**stdout 输出 JSON，stderr 输出错误，exit code 0/1**。

```
scripts/
├── README.md                          # 脚本清单 + CLI 接口 + 同步说明
├── transcribe_faster_whisper.py       # 音频转写 ASR（faster-whisper）
├── extract_keyframes.py              # 关键帧截图（FFmpeg）
├── download_video_candidates.py      # 视频下载（多 URL 候选）
├── download_youtube_subtitles.py     # YouTube 字幕下载（yt-dlp）
├── install_faster_whisper.py         # faster-whisper venv 自动安装
└── list_ai_douyin_tasks.py           # AI Douyin 任务查询
```

## 数据流

```
用户输入 URL/文件
       │
       ▼
  React 前端 ──Tauri IPC──▶ Rust 后端
                                 │
                                 ├── 步骤 0:  classifyInput() 识别输入类型
                                 ├── 步骤 1:  detect_python() 检查依赖
                                 ├── 步骤 2:  download / 本地准备
                                 ├── 步骤 3:  ffmpeg 提取音频
                                 ├── 步骤 4:  faster-whisper ASR 转写
                                 ├── 步骤 5:  extract_keyframes 关键帧
                                 ├── 步骤 6-7: MindEngine 调用 DeepSeek 生成笔记
                                 ├── 步骤 8:  清理临时文件
                                 └── 步骤 9:  更新修为面板
                                 │
                       ┌────────┴────────┐
                       │  Tauri Events    │
                       │  pipeline-progress  ──▶ 前端进度条
                       │  mind-stream        ──▶ 前端逐字渲染
                       └─────────────────┘
```

## 配置文件

| 文件 | 位置 | 内容 |
|------|------|------|
| `config.json` | `~/.myriad-mind-app/` | 非敏感配置（功能开关、ASR 参数、输出路径、模型参数） |
| API Keys | OS 密钥链 | DeepSeek Key / AI Douyin Key / TikHub Token / 火山引擎 Token |
| `tauri.conf.json` | `apps/desktop/src-tauri/` | Tauri 窗口、打包、资源绑定配置 |
| `pnpm-workspace.yaml` | 项目根 | pnpm workspace 包定义 |
| `CLAUDE.md` | 项目根 | Claude Code 项目指令（技术栈、架构、约束） |
