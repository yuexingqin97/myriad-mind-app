## 一、当前产品定位

大衍决 App 是一个本地优先的学习笔记生成工具。

核心路径：

```text
视频 / 文章 / 本地文件 / 代码项目
  → 内容获取
  → ASR / 文本提取 / 项目扫描
  → DeepSeek V4 Pro 长上下文炼化
  → 结构化 Markdown 笔记
  → 修为面板 / 搜索 / 对比 / 学习建议
```

## 三、v1.0 必须完成的核心需求

## 3.1 炼化首页

目标：从说明页升级为“左侧控制台 + 右侧 AI 输出区”的工作台。

需求：

- 输入链接 / 文件路径。
- 展示输入类型识别。
- 展示灵力预估。
- 展示配置可用性。
- 支持“本次要求”提示词 Hook。
- 右侧大区域流式展示 AI 输出。
- 生成完成后支持保存、复制、打开输出目录。

状态：

- UI 已基本完成。
- 需要接入真实 AI 输出流。

## 3.2 DeepSeek V4 Pro 接入

目标：先不追求多模型大全，优先吃透 DeepSeek V4 Pro 的 1M 上下文。

需求：

- `DeepSeekClient`
- `MindEngine`
- `mind-stream` 统一事件
- `deepseek-api-key` 写入 OS 密钥链
- 默认模型：`deepseek-v4-pro`
- 快速模型：`deepseek-v4-flash`
- 支持 `reasoning_content` 与最终正文分流
- 支持 standard / deep / fast 三种任务模式

关键约束：

- API Key 不进入 `config.json`。
- `reasoning_content` 不写入最终笔记正文。
- 长视频 / 长文档优先进入 1M 上下文，而不是过早摘要。

## 3.3 Skill 原型迁移

目标：把 `D:\Project\MyClaude\myriad-mind` 中已验证的能力迁移到 App。

优先迁移：

- 文章模式。
- 本地文本模式。
- 本地音频 / 视频模式。
- 在线视频基础管线。
- 灵力预估。
- 字幕引导截图。
- 修为面板真实扫描。

后续迁移：

- 代码项目分析。
- 搜索。
- 对比。
- 批量。
- AI Douyin 历史任务。

## 3.4 配置与引导

目标：用户首次启动后能完成最小配置，并知道缺什么。

需求：

- DeepSeek API Key 配置。
- Python / FFmpeg / yt-dlp / GPU 检测。
- 输出目录配置。
- ASR 策略配置。
- 视频解析 Provider 配置。
- 亮色 / 暗色 / 跟随系统。
- 阶段提示词 Hook 设置。

## 3.5 修为面板

目标：从 mock 仪表盘变成真实学习成果中心。

需求：

- 扫描 `note_dir` 下 Markdown。
- 解析笔记元信息。
- 统计笔记数、标签、难度、阅读时长、来源。
- 计算修为等级。
- 判定成就。
- 最近笔记列表。
- 打开笔记文件。
- 更新 / 生成 `修为面板.md`。

## 七、当前优先级排序

最短路径：

```text
DeepSeek V4 Pro
  → mind-stream
  → 文章 / 本地文本
  → 本地音视频
  → 在线视频
  → 字幕引导截图
  → 真实修为面板
```

不要同时开太多分支。

当前最该做的前三件事：

1. 实现 DeepSeek V4 Pro + MindEngine。
2. 让首页 AI 输出区接真实流。
3. 用文章 / 本地文本先跑通保存笔记闭环。
