## 一、当前产品定位

大衍决 App 是一个本地优先的学习笔记生成工具。

核心路径：

```text
视频 / 文章 / 本地文件 / 代码项目
  → 内容获取
  → ASR / 文本提取 / 项目扫描
  → DeepSeek V4 Pro 长上下文炼化
  → 结构化 Markdown 笔记
  → 修为面板 / 搜索 / 对比 / 学习建议
```

当前设计基线来自：

状态：✅ 完成

- UI 已基本完成。
- **已接入真实 AI 输出流**（`mind-stream` 事件，前端 `api.ts:253` / `usePipeline.ts:242` 监听）。
- 灵力预估前端已接入（`estimator.ts` + `InputView`）。
- "本次要求"提示词 Hook 已接入（提交 `c56aaa4`）。

## 3.2 DeepSeek V4 Pro 接入

状态：✅ 已实现

实际模块：

- `DeepSeekClient`（`ai/deepseek.rs`）：OpenAI-compatible chat completions + stream。
- `MindEngine`（`ai/engine.rs`）：统一 Prompt、模型调用、事件推送、4 种内容模式契约（视频 / 代码 / 网页 / 文档）。
- `mind-stream` 统一事件（payload 区分 `delta` / `reasoning` / `usage` / `done` 子类型）。
- `deepseek-api-key` 写入 OS 密钥链（Credential Manager，`engine.rs:23-31`：先读 config 兜底，再 `cred_read`）。
- 默认模型：`deepseek-v4-pro`（长上下文笔记生成）。
- 快速模型：`deepseek-v4-flash`（标题 / 资源推荐 / Vision 补全等快速任务，`deepseek.rs:26` / `engine.rs:443,464`）。
- `reasoning_content` 与最终正文分流（不写入笔记正文）。
- Vision 截图审查（`ai/vision.rs`，提交 `4d084e6`）：截图评分 / 选择 / 跳过原因。

关键约束（已落实）：

- API Key 不进入 `config.json`（仅在密钥链）。
- `reasoning_content` 不写入最终笔记正文。
- 长视频 / 长文档优先进入 1M 上下文，而不是过早摘要。
