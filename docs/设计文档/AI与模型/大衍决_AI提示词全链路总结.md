### 提示词 1：步骤 4.5 — 字幕分析 → 推荐截图时间点

**触发时机**：ASR 转写完成后，生成笔记之前

**SKILL 模板**（来自 SKILL.md 步骤 4.5）：

```text
Claude 分析字幕文本，识别出画面价值高的时刻，输出一份推荐截图时间点列表供下一步精准截图。

分析信号（从字幕中识别"这个时刻画面有价值"的线索）：

| 信号类型 | 典型表述 | 说明 |
| --- | --- | --- |
| 画面展示信号 | "看这段代码"、"如图所示"、"我们来看一下架构图"、"注意这个表格" | 讲师明确指向视觉内容 |
| 操作演示信号 | "点击这里"、"打开终端"、"运行一下"、"输入以下命令" | 教程操作步骤，需要截取界面 |
| 代码相关信号 | "这段代码的作用是"、"函数定义"、"配置文件" | 代码讲解，需要截取代码画面 |
| PPT 翻页信号 | "下一页"、"接下来看"、"第一个要点"、"这一章" | 章节过渡，通常伴随 PPT 翻页 |
| 对比/切换信号 | "对比一下"、"切换到"、"改成"、"前后的区别" | 画面变化，需要同时截取前后 |
| 运行效果信号 | "运行结果"、"输出是"、"报错了"、"执行效果" | 程序运行结果，需要截取终端输出 |

不推荐截图的时刻：
| 信号 | 典型表述 | 原因 |
| --- | --- | --- |
| 开场闲聊 | "大家好"、"我是XXX"、"欢迎来到" | 无信息量 |
| 纯口头讲解 | 无画面指涉的抽象概念讲解 | 字幕已覆盖 |
| 片尾/预告 | "下期再见"、"下节课我们会" | 无当前内容信息 |
| 过渡寒暄 | "好的"、"那我们继续"、"接下来" | 无视觉价值 |
```

**实际输入数据**：
- `text.txt`：46,256 bytes，约 15,000 个中文字符，覆盖 55 分钟视频
- 视频主题：Bevy ECS 源码分析

**预期输出格式**（JSON 文件）：
```json
[
  {"ts": 32.0, "reason": "PPT标题页：ECS三大核心概念"},
  {"ts": 95.0, "reason": "代码展示：Entity结构体定义"},
  ...
]
```

**实际输出**：17 个时间点，覆盖从程序运行效果(88s)到总结(3100s)的全程。

**🔴 断裂**：输出写入 `guided_timestamps.json` 时，Write 工具路径与 Bash `/tmp/` 不一致，文件未被步骤 4.7 读取。

### 提示词 3：步骤 7 — 生成学习笔记（核心提示词）

**SKILL 模板**（来自 SKILL.md 步骤 7）：

```text
请基于以下视频素材生成一份结构化学习笔记：

视频标题：{TITLE}
作者：{AUTHOR}
时长：{DURATION}
来源：{PLATFORM}
原始链接：{ORIGINAL_URL}

字幕文本（已翻译/原文）：
{TEXT_CONTENT}

AI 摘要：
{AI_SUMMARY}

关键帧截图（{FRAME_COUNT} 张）：
{列出 keyframes.json 中的文件和时间戳}

请生成以下内容：
0. **阅读信息**：推荐阅读时长 + 难度评级（见下方说明）
1. 核心概念（3-5 个最重要的概念）
2. 详细笔记（按内容逻辑分段，每段标注时间范围）
3. 关键画面描述（分析截图内容，标注时间点）
4. 关键术语表（英文术语 → 中文翻译 → 简要说明）
5. 总结与思考
6. 扩展学习资源（推荐进一步学习的方向和链接）
7. 评论区精华讨论（精选 3-6 条有价值的评论，附跳转链接；无高质量评论则跳过）
8. 知识关系图（Mermaid 图，展示本课核心概念及其关联结构）

**阅读时长计算（三步法）：**
- 第一步：基础阅读时间 = 正文总字数 / 400 字/分钟
- 第二步：图表浏览时间 = 每个 Mermaid +15s + 每张截图 +10s + 代码行 × 2s
- 第三步：难度系数修正（入门 ×1.0 / 进阶 ×1.3 / 深入 ×1.6）
- 公式：阅读时长 = (基础分钟 + 图表分钟 + 代码分钟) × 难度系数

**难度评级标准：**
| ⭐ 入门 🌱 | 面向零基础，无需前置知识 |
| ⭐⭐ 进阶 🌿 | 需要一定基础，涉及具体实现或原理分析 |
| ⭐⭐⭐ 深入 🌳 | 面向有经验者，涉及源码解读、底层机制 |

**内容可靠性评估：**
| ⭐⭐⭐ 可信 🟢 | 内容与官方文档一致 |
| ⭐⭐ 参考 🟡 | 大部分正确，有少量过时 API/版本差异 |
| ⭐ 谨慎 🟠 | 有争议内容、明显过时信息 |
| ⚠ 仅作了解 🔴 | 有已知事实错误 |

**重要格式要求：**
- 所有时间戳必须做成可点击的 Markdown 链接
- 格式：[MM:SS](视频链接?t=总秒数)
- 笔记段落标题格式：### [▶ MM:SS](链接?t=秒数) - MM:SS | 段落标题
- Mermaid 图表紧跟在相关文字之后
- 截图内嵌到对应知识点旁边
- 标签格式：#关键词，3-6 个

**Mermaid 图表要求：**
| 内容类型 | 推荐图表类型 |
| --- | --- |
| 架构/组件关系 | graph TD / flowchart |
| 流程/步骤 | flowchart LR / flowchart TD |
| 数据流/管道 | graph LR |
| 时序/步骤关系 | sequenceDiagram |
| 状态转换 | stateDiagram-v2 |
| 类/结构层级 | classDiagram |

**扩展学习资源要求：**
- 官方文档、同作者视频、GitHub 仓库、延伸阅读
- 5-8 个链接，附推荐理由
- 优先官方和权威来源
```

**实际填入的变量**：

| 变量 | 值 |
| --- | --- |
| `{TITLE}` | `[ecs] 重点之所在（全）` |
| `{AUTHOR}` | `机相的联失想` |
| `{DURATION}` | 55 分 35 秒 (3335s) |
| `{PLATFORM}` | B 站 (bilibili) |
| `{ORIGINAL_URL}` | `https://www.bilibili.com/video/BV14UzWBLEXD/` |
| `{TEXT_CONTENT}` | 46KB 中文字幕全文（约 15,000 字，ASR 转写） |
| `{AI_SUMMARY}` | 与笔记第一章合并生成 |
| `{FRAME_COUNT}` | 28 张截图 |
| `{keyframes 列表}` | keyframes.json 中的 28 个条目（全部 trigger:gap） |

**实际执行差异**：

| 要求 | 实际 | 原因 |
| --- | --- | --- |
| 关键画面描述 | ❌ 跳过 | PNG 截图不可渲染（`[Unsupported Image]`） |
| 截图嵌入正文 | ❌ 跳过 | 同上 |
| 评论区精华 | ❌ 跳过 | 缺少 B 站 `aid` 参数 |
| Mermaid 图表 | ⚠️ 减配（2张） | Token 约束，实际生成了知识关系图 + 核心概念图 |
| 阅读时长 | ✅ 28 分钟 | 公式计算：保守估算 |
| 难度评级 | ✅ 🌿 进阶 | ECS 需 Rust 基础 |
| 可靠性评级 | ✅ 🟡 参考 | 视频基于 Bevy 0.17，有版本差异 |
| 标签 | ✅ 5 个 | `#Rust #Bevy #ECS #源码分析 #进阶` |

**实际输出**：8,644 bytes 的 Markdown 笔记，包含 9 个笔记段落 + 术语表 + 知识关系图 + 扩展资源。

### 提示词 4：步骤 7.1 — 截图审查（🔴 未成功执行）

| 无字幕时间段 + 任何画面 | ×0.0（直接跳过） |

截图类型标签与基础分：
| 类型标签 | 基础分 | 判定标准 |
| --- | --- | --- |

| CODE_BLOCK | 3 | 代码 / 配置文件 / 终端输出 |
| ARCH_DIAGRAM | 3 | 架构图 / 流程图 / 数据流图 |
| RUN_RESULT | 3 | 程序运行效果 / 演示画面 |
| TOOL_UI | 3 | 编辑器 / IDE 操作界面 |
| DATA_TABLE | 2 | 数据表格 / 对比表 |
| TALKING_HEAD | 0 | 说话人脸画面 |
| PLAIN_TEXT | 0 | 纯文字段落（字幕已覆盖） |
| BLACK_SCREEN | 0 | 黑屏 / 过渡动画 |

评分公式：最终得分 = 基础分 × 上下文加成
≥ 3 → ✅ 必选
= 2 → ⚖️ 可选

## 二、提示词工程总结

### 提示词调用统计

| 步骤 | 提示词 | 状态 | 输入量 | 输出量 |
| --- | --- | --- | --- | --- |
| 4.5 | 字幕分析 | ⚠️ 输出丢失 | ~15,000 字 | 17 个时间点 |
| 5 | AI 摘要 | ✅ 合并执行 | ~15,000 字 | ~200 字摘要 |
| 6 | 语言检测 | ✅ | 46,256 chars | 跳过 |
| 7 | 笔记生成 | ⚠️ 减配 | ~15,000 字 + 28 截图(不可用) | 8,644 bytes |
| 7.1 | 截图审查 | ❌ 未执行 | 28 PNG | — |
| 7.3 | 知识关系图 | ✅ | 隐含在步骤 7 | 1 张 Mermaid |
| 7.4 | 教程检测 | ✅ 检测→未命中 | 标题+内容 | 不启用 |

### 提示词设计的断点

| 问题 | 说明 |
| --- | --- |
| **步骤 5 和 7 提示词高度重叠** | 两者都要求读字幕全文 → 生成总结 → 输出结构化内容。实际执行中被合并，步骤 5 的输出（摘要+要点）被步骤 7 覆盖 |
| **截图审查提示词无法执行** | 提示词中大量的截图审查规则（标签体系、评分公式、去重规则）在 PNG 不可渲染时全部浪费 |
| **提示词中硬编码了工具名称** | "用 Read 工具"、"用 Write 工具" — App 化后这些工具调用方式完全不同 |
