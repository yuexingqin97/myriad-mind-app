# 主题与配色设计

> 参考风格：CC Switch。目标是在大衍决桌面端中加入亮色模式、暗色模式和跟随系统模式，并统一炼化、修为、设置三大界面的视觉语言。

## 一、设计目标

主题系统需要解决三个问题：

1. 白天使用时，亮色模式足够干净、轻量、不刺眼。
2. 夜间使用时，暗色模式足够沉稳、聚焦、适合长时间阅读 AI 输出。
3. 两套主题共享同一套语义色，而不是各页面各自写颜色。

最终设置页中应提供：

```text
外观主题
[ 浅色 ] [ 深色 ] [ 跟随系统 ]
```

切换后立即生效，保存后下次启动沿用。

## 二、参考截图风格提炼

CC Switch 的视觉特点：

- 整体非常克制，界面以中性色为主。
- 主色是高饱和蓝色，主要用于按钮、选中态、焦点边框。
- 暗色模式不是纯黑，而是深灰黑。
- 亮色模式不是纯白卡片堆叠，而是大面积白底 + 细边框 + 蓝色强调。
- 卡片边框比阴影更重要。
- 选中项通常使用蓝色描边或浅蓝背景。
- 设置界面使用分段按钮、横向 Tab、轻量分组。

对大衍决的适配：

- 保留“大衍决”的学习工具气质，不做过度玄幻视觉。
- 紫色从主色降级为点缀色。
- 主操作色改为更通用、更清晰的蓝色。
- 修为相关可以保留少量金色 / 青绿色作为成就和成长感。

## 三、主题模式

### 3.1 浅色模式

适合：

- 白天使用。
- 设置、管理、浏览笔记列表。
- 更接近截图二的轻工具风格。

视觉关键词：

```text
干净、轻量、边框清晰、蓝色强调、低阴影
```

### 3.2 深色模式

适合：

- 夜间使用。
- 长时间看 AI 输出。
- 更接近截图一的沉浸式工具风格。

视觉关键词：

```text
沉稳、低亮度、弱分隔、蓝色聚焦、输出区突出
```

### 3.3 跟随系统

行为：

- 读取系统主题。
- 系统切换时应用自动切换。
- 用户显式选择浅色 / 深色后，不再跟随系统。

## 四、语义色设计

不要在组件里直接写固定颜色，应使用语义变量。

```text
--bg-app          应用背景
--bg-sidebar      侧边栏背景
--bg-surface      普通容器背景
--bg-elevated     强调容器背景
--bg-input        输入框背景

--border-subtle   弱边框
--border-default  默认边框
--border-strong   强边框 / 选中边框

--text-primary    主文字
--text-secondary  次级文字
--text-muted      弱文字
--text-inverse    反色文字

--brand-primary   主色
--brand-hover     主色 hover
--brand-active    主色 active
--brand-soft      主色浅背景

--success         成功
--success-soft    成功浅背景
--warning         警告
--warning-soft    警告浅背景
--danger          错误
--danger-soft     错误浅背景
--info            信息
--info-soft       信息浅背景

--cultivation     修为强调色
--cultivation-soft
```

### 浅色模式使用建议

- 页面背景使用 `--bg-app`，保持大面积干净。
- 卡片使用白底 + `--border-default`，尽量少用大阴影。
- 选中态使用 `--brand-soft` 背景 + `--brand-primary` 文字。
- 输入框边框默认浅灰，聚焦时变蓝。
- 设置页可以最大程度参考截图二：白底、顶部标题、分段控件、蓝色选中。

## 七、组件配色规范

### 7.1 侧边栏

浅色：

- 背景：`--bg-sidebar`
- 边框：`--border-subtle`
- 文字：`--text-secondary`
- 激活：蓝色浅底 + 蓝色文字

深色：

- 背景：`--bg-sidebar`
- 边框：`--border-default`
- 激活：`--brand-soft`

### 7.2 主按钮

```text
默认：蓝底白字
hover：更亮或更深的蓝
disabled：降低透明度，不改变布局
```

浅色和深色都统一使用蓝色主按钮。

### 7.3 次级按钮

浅色：

- 白底
- 灰边框
- 深灰文字

深色：

- 深灰底
- 灰边框
- 浅灰文字

### 7.4 输入框

浅色：

- 白底
- 浅灰边框
- 聚焦蓝色边框

深色：

- 深灰底
- 灰边框
- 聚焦蓝色边框

输入框不要使用过强阴影。

### 7.5 卡片

浅色：

```text
白底 + 浅灰边框 + 轻微 hover 边框变化
```

深色：

```text
深灰底 + 中灰边框 + 选中时蓝色描边
```

重要卡片选中态：

```text
border: 1px solid var(--brand-primary)
background: var(--brand-soft)
```

### 7.6 状态徽章

```text
已就绪：绿色
可降级：黄色
阻塞：红色
未配置：灰色
进行中：蓝色
```

示例：

```text
Claude 已配置
FFmpeg 缺失
GPU 可选
正在生成
```

## 八、三大界面主题适配

## 8.1 炼化页

布局方向：

```text
左侧控制台 + 右侧 AI 输出区
```

深色模式：

- 右侧 AI 输出区使用更深背景，突出阅读体验。
- 生成中状态用蓝色进度。
- Markdown 内容文字用高对比浅色。

浅色模式：

- 输出区白底。
- Markdown 代码块用淡灰背景。
- Mermaid / 关键帧区域用浅边框分隔。

炼化页重点色：

- 主操作：蓝色。
- 生成中：蓝色。
- 成功完成：绿色。
- 管线失败：红色。

## 8.2 修为页

修为页需要一点“成果感”，但不能花。

建议：

- 当前境界使用 `--cultivation` 点缀。
- 进度条可以用蓝色到金色的轻渐变。
- 成就图标使用金色点缀。
- 数据卡片仍保持中性色。

浅色修为页：

```text
白底 + 金色小面积点缀 + 蓝色操作按钮
```

深色修为页：

```text
深灰底 + 金色成就点缀 + 蓝色选中/操作
```

避免：

- 大面积金色背景。
- 大面积紫色渐变。
- 太玄幻的发光效果。

## 8.3 设置页

设置页最贴近 CC Switch 截图二。

浅色模式：

- 白底。
- 顶部标题区。
- 横向 Tab 或左侧导航。
- 分段按钮使用蓝色选中。
- 表单分组用细分隔线。

深色模式：

- 参考截图一。
- 页面背景深灰。
- 配置卡片边框清楚。
- 当前选中项使用蓝色描边和轻微蓝色背景。

设置页重点：

- 让“可用 / 缺失 / 可选”状态很清楚。
- 不要为了装饰牺牲可读性。

## 九、主题切换交互

设置页中加入“外观主题”配置：

```text
外观主题
选择应用的外观主题，立即生效。

[ 浅色 ] [ 深色 ] [ 跟随系统 ]
```

行为：

- 点击即切换主题。
- 普通配置保存后持久化。
- 如果选择“跟随系统”，监听 `prefers-color-scheme`。

配置字段建议：

```ts
appearance: {
  theme: "light" | "dark" | "system";
}
```

如果暂时不想改 core schema，可以先在桌面端 localStorage 中存：

```text
myriad-mind-theme = light | dark | system
```

后续再迁移进统一配置。

## 十、主题变量落地建议

第一阶段：

- 在 `App.css` 中建立 `data-theme="light"` 和 `data-theme="dark"` 变量。
- 把现有固定色逐步替换成语义变量。
- 默认主题可先设为 `dark`，保持当前体验稳定。

第二阶段：

- 设置页加入主题切换。
- 应用启动时读取主题。
- 切换时更新 `document.documentElement.dataset.theme`。

第三阶段：

- 把 `Button`、`Card`、`Input` 中的 inline 固定色替换为 CSS 变量。
- 统一 packages/ui 和 apps/desktop 的视觉 token。

## 十一、验收标准

- 设置页可以选择浅色、深色、跟随系统。
- 切换主题无需刷新页面。
- 三个主页面在两套主题下都可读。
- 主按钮、选中态、焦点态统一使用蓝色。
- 暗色模式不是纯黑，亮色模式不是大面积灰底。
- 状态色语义一致：绿成功、黄警告、红阻塞、蓝进行中。
- AI 输出区在亮色和暗色下都适合长时间阅读。
