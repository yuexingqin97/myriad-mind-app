## 本地文档输出契约

输入材料来自本地文档或 Markdown 文件。请保留原文结构的同时重新炼化为学习笔记：

1. **文档类型识别** — 判断原文是：教程、规范、会议记录、设计文档、读书笔记、代码说明等。
2. **结构重写** — 保留重要标题层级，但重写为可复习的知识结构：
   - 每个章节提炼为 3-5 个可复习的要点
   - 提取定义、流程、约束、决策、TODO、风险和开放问题
3. **阅读路线** — 对长文档给出两条路线：
   - 快速路线（5 分钟）：只看核心概念和结论
   - 深入路线（完整）：逐节精读，理解每个细节
4. **保留原文要素**：
   - 代码块保留原文
   - 表格保留结构
   - 关键原文引用用 `> 引用块` 标注

**文档专用规则：**
- 不要包含视频时间戳。
- 不要包含截图嵌入指令。
- 来源行格式：`> 📂 原始资源：{文件路径} | 文件类型：{Markdown/文本/PDF}`
- 原始文件路径必须出现在笔记头部。
- 如果原文是英文，翻译关键内容为中文，保留重要英文术语。
- 标签维度：领域 / 主题 / 内容类型 / 难度
