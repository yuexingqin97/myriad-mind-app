## 后续修复：B站 / 在线视频下载链路

在 task2 验证完成后，继续排查并修复了用户反馈的 B站视频下载失败问题。相关修改仍落在本次 Python→Rust 迁移后的 Rust 代码路径上，因此一并归入 task2 证据。

### 问题现象

1. `download_video` 工具对 B站链接返回 `API 返回 500`。
2. `fetch_url` 抓取 B站页面返回 gzip 二进制乱码，无法解析。
3. `query_ai_douyin` 查询任务列表失败。
4. `yt-dlp` 下载 B站时因浏览器 Cookie 数据库被锁住，报错 `Could not copy Chrome cookie database`。

### 修复内容

#### 1. `apps/desktop/src-tauri/Cargo.toml`

为 `reqwest` 增加 `gzip` feature，解决 `fetch_url` 抓到 gzip 压缩体后无法自动解压的问题。

```toml
reqwest = { version = "0.12", features = ["json", "stream", "gzip"] }
```

#### 2. `apps/desktop/src-tauri/src/commands/pipeline.rs`

`download_video_ytdlp` 函数：

- 所有 yt-dlp 调用增加 `--ignore-config`，防止用户全局配置里写了 `--cookies-from-browser` 导致锁库报错。
- 新增读取配置项 `ytdlp_cookies_file`，若存在则传入 `--cookies <path>`。
- B站 412 回退逻辑优先使用配置的 `cookies.txt`；没有配置时才回退到 `--cookies-from-browser edge`。
- 优化错误提示：区分 "Cookie 数据库被锁住" / "412 需要登录态" / 其他错误，给出可操作的中文解决方案。

#### 3. `apps/desktop/src-tauri/src/commands/tools/handlers/acquire.rs`

`DownloadVideoHandler` 路由调整：

- **B站**改为**先走 yt-dlp**，失败后再回退 AI Douyin。
- **抖音/小红书**仍优先走 AI Douyin。
- **YouTube** 走 yt-dlp 不变。

这样避免 B站继续白扣 AI Douyin 积分并撞上其不稳定的 500 错误。

#### 4. 环境配置

- 为用户安装/更新了 `yt-dlp`（版本 `2026.06.09`）并放到 PATH。
- 在 `~/.myriad-mind-app/config.json` 中配置了 `ytdlp_cookies_file`，指向用户导出的 B站 `cookies.txt`。
- 指导用户用 Edge 的 `Cookie Editor` 扩展以 Netscape 格式导出 `bilibili_cookies.txt`。

## 最后一次补充：音频提取与 agent 路径修复

在用户提供“最后一次补充机会”后，把上一份文档中提到的关键修复建议落地为代码，并完成验证。

### 已修复问题

1. **`extract_audio` 报错笼统**
   - 文件：`apps/desktop/src-tauri/src/commands/pipeline.rs`
   - 修改：`extract_audio_ffmpeg` 现在用 ffprobe 前置检查音频流；ffmpeg 失败时捕获 stderr 并返回具体错误。
   - 收益：如果视频没有音频流，会明确提示而不是模糊的“FFmpeg 音频提取失败”。

2. **agent 看不到 artifact 绝对路径**
   - 文件：`apps/desktop/src-tauri/src/agent/context.rs`
   - 修改：`TaskState::to_yaml()` 现在为每个 artifact 输出 `path` 字段，并附加强调使用绝对路径的 note。
   - 收益：agent 调用 `extract_audio`、`scan_directory`、`read_file` 时可以使用真实路径，而不是 `temp_dir/...` 占位符。

3. **路径沙箱报错不够明确**
   - 文件：`apps/desktop/src-tauri/src/commands/tools/mod.rs`
   - 修改：`resolve_readable` 返回的错误现在会列出所有允许的根目录。
   - 收益：agent 收到错误后能自己修正到合法路径。
