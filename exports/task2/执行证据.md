## 三、关联修复（方案 A）：下载子进程总超时兜底

> 迁移验证中发现 `download_video_candidates.py`（**保留脚本**，非迁移对象）在 B 站直链下载阶段永久卡死（实测 17 分钟无响应）。属中转层既有缺陷，顺手在 Rust 封装层补齐。详见迁移计划 §七。

**根因**：`run_python_script` 用 `Command.output().await` 无限期等子进程；脚本 `urllib.urlopen(timeout=30)` 是 socket 级超时，慢速 CDN 持续 dribble 时永不超时 → 子进程卡死 → Rust 卡死 → Agent 卡死。

**修复（2 处）**：
1. `python.rs::run_python_script`：子进程加 `kill_on_drop(true)`（封装层全局防孤儿，正常完成无副作用）。
2. `pipeline.rs::download_douyin_video`：`tokio::time::timeout(300s)` 包裹下载，超时杀子进程返回错误 → B 站自动 fallback yt-dlp（`acquire.rs` 既有分支）。

**边界**：不动 Python 脚本（黑盒）；超时值 300s 硬编码。
