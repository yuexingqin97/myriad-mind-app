## 五、调用链变更

```
旧（Python 中转）:
  acquire.rs → python::list_ai_douyin_tasks(python_path, api_key, ...)
    → run_and_parse() → run_python_script() → Command::new("python")
      → subprocess: python list_ai_douyin_tasks.py --api-key {key} --json
        → urllib.request.urlopen(GET /api/v1/tasks)

  pipeline.rs → extract_keyframes_guided(python_path, video, output_dir, timestamps)
    → run_python_script("extract_keyframes.py") → Command::new("python")
      → subprocess: python extract_keyframes.py --video ... --mode scene ...
        → subprocess.run(["ffmpeg", ...])

新（Rust 直连）:
  acquire.rs → ai_douyin::list_ai_douyin_tasks(api_key, ...)
    → reqwest::Client::get(url).header("X-API-Key", key).send()

  pipeline.rs → extract_keyframes_guided(_python_path, video, output_dir, timestamps)
    → media::extract_keyframes_guided(video, output_dir, timestamps)
      → std::process::Command::new("ffmpeg").args([...]).output()
```

## 七、用户追问：`tsc && vite build` 报错分析

**问题**：`Cannot find module '@myriad-mind/ui'` / `'@myriad-mind/core'`

**诊断**：与本次迁移**完全无关**。报错原因：

```
packages/core/dist/  ← 不存在（从未编译）
packages/ui/dist/    ← 不存在（从未编译）
```

这是 monorepo 构建顺序问题：`packages/core` 和 `packages/ui` 是 workspace 内部包，它们的 `package.json` 中 `"types": "./dist/index.d.ts"` 指向 `dist/` 目录，但该目录从未被 `tsc` 产出过。`apps/desktop` 的 TypeScript 编译器需要这些 `.d.ts` 才能解析 `@myriad-mind/*` 导入。

**修复**：执行 `pnpm build`（按依赖拓扑顺序：core → ui → desktop），之后 `tsc` 即可正常通过。

**证据**：`packages/core` 自身的 `tsc --noEmit` 检查**通过**（见上文 pnpm typecheck 输出中 `packages/core typecheck: Done`），验证本次迁移未破坏 TS 类型。
