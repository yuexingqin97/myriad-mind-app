## 一、Vite 启动报错：Failed to resolve entry for package

### 现象

启动 `pnpm dev` 报错：
```
[plugin:vite:import-analysis] Failed to resolve entry for package "@myriad-mind/core"
[plugin:vite:import-analysis] Failed to resolve entry for package "@myriad-mind/ui"
```

### 原因

`packages/core` 和 `packages/ui` 的 `package.json` 都把 `main` 指向 `./dist/index.js`，但首次 clone 后 `dist/` 不会自动生成（pnpm install 只装依赖不构建），Vite 找不到入口文件。

### 解决

```bash
pnpm --filter @myriad-mind/core build
pnpm --filter @myriad-mind/ui build
# 或一步到位
pnpm build
```

之后 `pnpm dev` 正常启动（Vite HTTP 200 验证通过）。

> 注意：以后改 `packages/core/src` 或 `packages/ui/src` 后需重新 build，或开 `dev` watch 模式。

## 二、App 下载视频链路分析

### 问题

用户问：调用 App 分析日志，下载视频尝试是什么链路，竟然成功了？

### 日志分析

日志位置：`C:\Users\zhangxiaoyue\.myriad-mind-app\logs\myriad-mind.log`（2.2MB）

目标视频：B站 BV1n2jy6qETM

#### 下载链路（2 步）

```
12:16:50  Agent 调用 download_video 工具
    │
    ├─① Rust: resolve_via_ai_douyin()  [pipeline.rs:602]
    │   reqwest POST → https://ai-douyin.top9.cc/api/v1/video/download-url
    │   带 X-API-Key 头（用户配置的 ai_douyin_api_key）
    │   ↓ 返回 JSON（325 字节）
    │   {
    │     "download_url": "https://ai-douyin.top9.cc/api/video/download-file?url=...BV1n2jy6qETM",
    │     "download_urls": ["https://ai-douyin.top9.cc/api/video/download-file?url=..."]
    │   }
    │   → 写入 temp/download_url.json
    │
    ├─② Python: download_video_candidates.py  [仍为 Python 脚本，未迁移]
    │   urllib GET → https://ai-douyin.top9.cc/api/video/download-file?url=...
    │   带 X-API-Key + User-Agent 头
    │   逐个尝试候选 URL，下载到 video.mp4
    │   ↓ 38 秒，9.5MB，exit_code=0 ✓
    │
12:17:31  下载完成 → video.mp4 (9542081 bytes)
```

### 为什么成功

AI Douyin API 返回的不是 B站直链，而是一个**中转代理 URL**：
```
https://ai-douyin.top9.cc/api/video/download-file?url=https%3A%2F%2Fwww.bilibili.com%2Fvideo%2FBV1n2jy6qETM
```

AI Douyin 服务端替用户向 B站请求视频流再转发回来，**绕过了 B站的 412 风控**。

对比日志中后续 yt-dlp 直接请求 B站 API 就吃了 412：
```
[python] phase=failed script=download_youtube_subtitles.py exit_code=1
stderr_summary="ERROR: [BiliBili] 1n2jy6qETM: Unable to download JSON metadata: HTTP Error 412"
```

### 链路中两段分工

| 步骤 | 实现语言 | 职责 | 是否已迁移 |
|------|---------|------|-----------|
| ① 解析 URL | **Rust** (reqwest) | 调 AI Douyin API 拿下载直链 | 本来就是 Rust |
| ② 下载视频 | **Python** (urllib) | 从候选 URL 下载实际视频文件 | ❌ 保留（迁移计划标记为"半迁"） |

`download_video_candidates.py` 属于迁移计划里"⚠️ 半迁"的脚本——API 查询已用 Rust，下载部分仍保留 Python（因为可能扩展用 yt-dlp 下载）。本次迁移未涉及此脚本。
